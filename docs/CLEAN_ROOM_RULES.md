# REA & Clean Room Design Protocol

1. **DECONSTRUCTION ONLY**: We study competitors to understand *how* they handle complex variables (e.g., WTI compliance, shift swapping, labor cost previews).
2. **ABSTRACT TRANSLATION**: Extract only the logic diagram and state machine.
3. **ORIGINAL EXECUTION**: Rebuild the feature from scratch using our exact stack. Never adapt competitor code; write native Python/OR-Tools logic.

**Activated via:** `/rea-analyze` command  
**Reference competitors:** Deputy, 7shifts (architecture/UX inspiration only — never code)
